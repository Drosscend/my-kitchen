## Architecture

Read [the application architecture](docs/architecture/application.md) before adding or refactoring controllers, Actions, Queries, repositories, domain objects, or capability boundaries.

Read [the glossary](CONTEXT.md) before naming or changing domain concepts.

Use Kysely with Postgres for persistence. Keep database invariants in migrations and persistence mapping inside repositories. Prefer explicit read models for non-trivial reads and domain objects for command paths that enforce business rules. Every aggregate root has a cuid2 primary key generated by the application through an `Identifier` subclass; line items owned by an aggregate (recipe ingredients and steps, ingredient batches) take a raw cuid2, and cooking sessions are keyed by their six digit code.

## Capabilities

`identity` (accounts, connected applications), `inventory` (the pantry), `recipes` (the library) and `cooking` (shared sessions) each have their `app/<capability>` delivery slice and `src/<capability>` core. `app/mcp` is delivery only: it adapts the MCP SDK to the same Actions and Queries, one stateless server per request bound to the token owner. `app/oauth` mounts the oidc-provider authorization server that issues those tokens; its storage lives in `src/identity`.

## Interface

Pages live in `inertia/pages`, built with the shadcn components of `inertia/components/ui` (Base UI, Vega style, `cva`, `cn`) and the Carnet aimanté theme of `inertia/css/app.css` (Bricolage Grotesque, kraft paper, magnet colours `mustard`, `tomato`, `sage`, `cornflower` and `cinnamon`, utilities `magnet`, `highlight`, `paper-stack`, `ruled` and `page-width`, light only). Tailwind classes live in `className` only, never in a constant or a lookup table: a variant goes through a `data-*` attribute and `data-[…]:` classes, a colour through `data-swatch`, a grid shared by several elements through a CSS variable set on their parent, a recurring block through an `@utility`. Recipe steps and notes are edited with TipTap, a step mentioning ingredients as inline nodes. Phones get a bottom tab bar and `DialogSheet` docks dialogs to the bottom of the screen. Use `Link` and `Form` from `@adonisjs/inertia/react` with a typed `route`. React Compiler is on: no `useMemo`, `useCallback` or `memo`.

## Verification

Run `npm run lint`, `npm run format`, `npm run typecheck`, and `npm test` before committing. Tests need the local Postgres and a `my_kitchen_test` database. Use Conventional Commits, in English.
