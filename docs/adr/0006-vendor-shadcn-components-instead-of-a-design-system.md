# Vendor shadcn components instead of a design system package

The reusable UI is the set of shadcn components (Base UI variant, Vega style) copied into `inertia/components/ui`, styled through `cva` and `cn`, with the Carnet aimanté theme in `inertia/css/app.css`. They stay diffable with the registry: both Oxlint and Oxfmt ignore the folder, and they are regenerated rather than edited: the shadcn CLI runs in a scratch project (style `base-vega`, `cn` as the utils alias, `~` mapped by its tsconfig) because it does not resolve the `~` alias from this repository's root, then the files are copied over. The only local adaptation is the Toaster, pinned to the light theme instead of reading `next-themes`. A separate design-system package, Ark UI, and Storybook were left out: one application consumes these primitives.
